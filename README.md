### How I work

- I put error tracking, structured logs and a health check in place before the first user arrives.
- I default to boring technology: PostgreSQL, Docker, plain REST. I only add something new when the old option clearly fails.
- I use a monorepo (Nx, Melos) when the client and server ship together, and keep shared types in one place.
- I treat LLMs as a feature behind a normal API, with rate limits, retries and cost controls, not as the product itself.
- I build for local constraints: Persian text, Jalali dates, Iranian payment gateways and SMS providers.
